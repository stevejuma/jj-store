# jj-store

## 0.1.0

Initial experimental native JJ storage, projects, collaboration, agent/review
records, workflows, browser UI and rebuildable custom-data indexes. Distribution
includes coordinated Cargo packages, complete Linux/macOS command-line bundles,
an authenticated external-RustFS image and published specifications.

Qualification limits remain in the milestone ledger. Subsequent notes are
generated through Changesets.
