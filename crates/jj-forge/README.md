# jj-forge

Forge adapters, guarded stack submission and recoverable external-effect
journals for jj-store. GitHub, GitLab and Forgejo share owned contracts; saved
GitHub accounts resolve credentials through native OS credential storage. Tokens
and external-effect journals never become repository authority.

[Repository](https://github.com/stevejuma/jj-store) ·
[Specification](https://stevejuma.github.io/jj-store/)

Experimental 0.1 releases; live provider and platform qualification remain
separate gates in the milestone ledger. Licensed under Apache-2.0.
