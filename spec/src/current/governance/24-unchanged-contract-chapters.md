# Unchanged-contract chapter lookup

JST-GOV-002 and JST-GOV-011 allow a fresh, qualified unchanged-contract
confirmation when implementation preserves an existing contract. A requirement
may be defined in a table and explained in a separately mapped canonical topic.
The confirmation provider resolves the confirmed IDs to both their definitions
and canonical contract/governance pages that explicitly reference those exact
IDs. The configured production-to-topic ownership mapping remains authoritative.
Navigation pages, historical evidence, background documents and partial ID
matches cannot supply a canonical confirmation.

Existing evidence freshness, complete protected-path coverage, known requirement
IDs, passing completed validation, immutable history and explicit milestone
review remain required. Revision-pinned reads and all-parent/range integrity
checks still apply. E-CONFIRMATION-CHAPTERS-001 records the regression and
checks.

E-CI-CLIPBOARD-STABILITY-001 retains JST-GOV-002/011 governance. The browser
test refactor updates its mapped CI contract, records failed prerequisites and
passing focused checks, preserves incomplete M30 gates and supplies a fresh
milestone review. Product presentation and clipboard behavior are unchanged.
