# Local Stacks main-workspace integration

The integration preserves the completed Stacks history and Main's bounded
file-read changes. Shared folder bindings retain cached traversal validation and
fresh authorization at read boundaries while exposing the registered physical
folder to Stacks and working-tree handlers. Recovery reads retain exact native
extras and the cached Git handle. Merge verification covers these affected Rust
packages, local route and admission regressions, combined generated contracts,
Stacks/navigation/loading and directory consumers, plus fresh browser stories.
Both parents' historical evidence payloads remain unchanged; integration adds
evidence without promoting milestones or replacing existing live services.
