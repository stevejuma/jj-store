# Repository-owned presentation

The ui-ownership plugin runs during spec validation, normal checks and aggregate
spec checks. The focused `pnpm check:ui-ownership` command runs that plugin
only. It checks executable imports, package/lockfile/configuration entries,
source links and the local provenance manifest. Documentation attribution and
explicit negative fixtures are permitted. Design Core and Mira remain
foundational dependencies. Visual fidelity is established by browser and
interaction evidence, not by dependency exclusion. Existing Community package
qualification is historical evidence; new slices copy the necessary source
closure locally. The extracted directory attribution component retains its
parent directory component's pinned Community source and Apache-2.0 license. Its
Snapshot icon and truncated commit subject remain repository-owned presentation
with focused interaction and layout evidence.

Shared repository card surface tokens are maintained locally with their original
Community graph source and license in the provenance manifest. Pointer hover,
the Command View keyboard cursor and the selected native bookmark are separate
presentation states. Browser evidence checks their surfaces against Op Log
across the complete theme catalog; focused menu/card stories retain blocking
interaction, accessibility and runtime diagnostics.


E-CHAT-WORKSPACE-005 extracts the repository file loading skeleton for reuse by
inbox workspace inspection. Its original file-panel and stylesheet revisions and
Apache-2.0 attribution are retained in `docs/ui-provenance.json`. JST-GOV-008 is
unchanged: the shared implementation remains locally owned and uses released
Design Core Skeleton primitives, without a Community checkout dependency.
