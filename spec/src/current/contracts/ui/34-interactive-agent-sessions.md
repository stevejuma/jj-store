# Interactive agent execution

Agents retains its recorded session directory and adds New session and Saved
setups. New sessions choose an authorized repository and exact revision, create
an isolated workspace, negotiate live runtime options, then send an explicit
prompt. Repository/project/task actions prefill visible exact context.
Conversation layout adds a persistent composer, queued follow-ups, live
tools/plans, exact permission cards, stop/end/resume and review links.
Community-derived presentation stays owned under web/src/lib; Design Core
remains a released dependency. Operational feedback uses application toasts and
drafts survive failed/unknown commands.

Activity-stream reconnection retains explicit command refusals independently. A
valid recovered event frame resolves the stream condition; unrelated status
refreshes do not erase command errors or imply stream recovery. Reconnection
only requests retained event ranges and never dispatches a prompt or command.

Conversation message text inherits the released Design Core bubble foreground.
Muted-caption styles apply only to application-owned headers and status text,
not Markdown message paragraphs. Cold browser accessibility includes actual
foreground/background color contrast for populated user and assistant bubbles.
