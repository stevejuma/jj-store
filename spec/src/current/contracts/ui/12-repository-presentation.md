# Repository presentation

Branches are JJ bookmarks; conflicted bookmarks show every target and deleted
bookmarks show empty history. A branch, revision and file occupy successive
Column Canvas path levels. Changing an earlier selection clears later selection.
JJ Log preserves divergent same-change commits; only duplicate native IDs may
collapse. Operation siblings remain visible and opening details publishes
nothing. Full-ID clipboard controls never construct Community routes. Source
strings render as data; file/diff controls retain public Design Core semantics.

Repository unavailable-content banners use the shared column alert's inset
presentation, with 8px vertical margin, internal padding and a complete rounded
border. Agent sessions and unavailable Review/Agent response details use the
collection's 16px side inset and rounded corners. The Reviews directory banner
aligns both edges and corner radius with its surface header. Narrow panes retain
the inset without horizontal overflow. Themes, severity icons and contextual
content remain intact. Integrated column validation and exact-request recovery
alerts retain their existing presentation; transient read failures keep their
scoped toast lifetime under JST-UI-019.

Collapsible collection headings retain the shared secondary text size and the
application font family. Button font inheritance MUST NOT reset that size;
Agents and the other repository/Projects collections use the same scale.
