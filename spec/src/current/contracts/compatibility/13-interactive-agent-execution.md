# Interactive agent execution qualification profile

JST-COMPAT-001, JST-COMPAT-003 and JST-COMPAT-005 retain their JJ 0.45.1,
manifest-selected authority and embedded-RustFS requirements. Interactive
execution adds strict installation-local HTTP schemas and control version 2
without changing native object/manifest identity encodings. The private
execution journal is installation state; it is not a repository format or
authority.

Read-only recorded_session_ids, workspace_name and workspace_operation are
additive local status fields with legacy journal defaults. Stored projections
are discarded; status derives them from committed normalizer aliases and ready
workspace proofs. Original setup association and captured name/avatar survive
restart and setup editing/deletion. JST-COMPAT-001/JST-COMPAT-003/JST-COMPAT-005
native identities, canonical repository formats and qualification scope remain
unchanged; no repository migration or historical republishing is required.

M23 qualifies installed Codex and Cursor independently against ordinary
registered Git-backed JJ folders and linked native repositories with real
RustFS. Dirty source files are preserved; only the new isolated workspace is
edited. Qualification also requires sanitized durable AgentStore history, cold
browser/restart and managed owner-lifetime evidence. Real edit turns that raise
no permission requests cannot establish live permission exchange; exact options,
cancellation and deadlines remain separately identified fixture proof.

This profile does not qualify signed desktop distribution, WKWebView packaging,
other platforms or adapters, automatic merging/pushing, credential provisioning,
replication, backups or source-folder migration.

Runtime-management qualification distinguishes fixed-catalog fixture installs,
real disposable npm downloads and authenticated provider sessions. macOS/Linux
Node.js 22+ with npm is the initial installer prerequisite. Codex ACP 1.13.1 and
CLI 0.156.1 are the maintained catalog targets. Startup/private selection,
failed-update retention, interruption, process-group teardown, typed Admin
admission and cold settings UI require focused evidence. Private Node
provisioning, managed Cursor installation, other harnesses and visual baselines
remain separate.
