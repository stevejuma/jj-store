# Interactive agent execution qualification profile

JST-COMPAT-001, JST-COMPAT-003 and JST-COMPAT-005 retain their JJ 0.45.1,
manifest-selected authority and embedded-RustFS requirements. Interactive
execution uses strict installation-local HTTP schemas and Control V3 without
changing native object/manifest identity encodings. The private execution
journal is installation state; it is not a repository format or authority.

Read-only recorded_session_ids, workspace_name and workspace_operation are
additive local status fields with legacy journal defaults. Stored projections
are discarded; status derives them from committed normalizer aliases and ready
workspace proofs. Original setup association and captured name/avatar survive
restart and setup editing/deletion. JST-COMPAT-001/JST-COMPAT-003/JST-COMPAT-005
native identities, canonical repository formats and qualification scope remain
unchanged; no repository migration or historical republishing is required.

M23 qualifies installed Codex and Cursor independently against ordinary
registered Git-backed JJ folders and linked native repositories with real
RustFS. Dirty source files are preserved; only the new isolated workspace is
edited. Qualification also requires sanitized durable AgentStore history, cold
browser/restart and managed owner-lifetime evidence. Real edit turns that raise
no permission requests cannot establish live permission exchange; exact options,
cancellation and deadlines remain separately identified fixture proof.

This profile does not qualify signed desktop distribution, WKWebView packaging,
other platforms or adapters, automatic merging/pushing, credential provisioning,
replication, backups or source-folder migration.

Runtime-management qualification distinguishes fixed-catalog fixture installs,
real disposable npm downloads and authenticated provider sessions. macOS/Linux
Node.js 22+ with npm is the initial installer prerequisite. Codex ACP 1.13.1 and
CLI 0.156.1 are the maintained catalog targets. Startup/private selection,
failed-update retention, interruption, process-group teardown, typed Admin
admission and cold settings UI require focused evidence. Private Node
provisioning, managed Cursor installation, other harnesses and visual baselines
remain separate.

M24 adds explicitly selected control version 3, warm workers, conversation homes
and additive local status/binding fields with journal defaults. Canonical
AgentStore and ThreadStore formats and manifest/ref-CAS authority remain
unchanged. Historical M23 version-2 evidence stays separate; current M23/M24
execution uses Control V3 exclusively. Fleet fixture, installed adapters, native
materialization and cold built-browser gates are recorded independently.

Workspace inspection adds strict typed read DTOs and private execution events
for exact pre-dispatch snapshots. Legacy records missing a start boundary remain
readable and report Last turn unavailable. This preserves JST-COMPAT-001/003/005
native widths, object encodings, publication authority and independent native
qualification. Local review-anchor publication is still a separate M13.3 gate.

The version-1 read DTO adds optional additions/deletions, omitted or null when
unknown. Legacy readers and responses remain valid; native object, manifest,
journal and companion formats require no migration. E-CHAT-INSPECTOR-001
verifies generated OpenAPI and an actual response independently of release
qualification.

The shared review envelope adds portable file target tags using the existing V2
code-selector types. Existing native and repository target bytes remain exact.
Local review descriptors add an optional evidence inventory, omitted when empty
to preserve existing encodings. Native portable carriers, portable agent review
publication and conversion of those anchors remain separately unqualified.

The additive repository_review_comment target includes repository identity;
legacy reference bytes and tokens remain unchanged. Optional frozen file context
is omitted when absent. JST-COMPAT-001/003/005 preserve native/local source
widths, canonical stores and independent authorization. Local/native conversion
refuses these references until qualified mapping exists rather than remapping
IDs.

The optional omitted-empty workspace comment draft list preserves existing
submission encodings. Private journal maps retain deferred prompts, per-source
snapshot attempts, captured review commands and exact results. Restart retains
these records and marks interrupted delivery unknown; it does not replay
prompts. ThreadStore refuses unresolved drafts, preserving the old publication
authority.

E-CHAT-WORKSPACE-009 adds optional, omitted-when-unknown `workspace_name` to
code-binding status, derived from the existing retained proof. Legacy journals
remain readable. JST-COMPAT-001/003/005 native identities, source selections and
publication formats are unchanged. New physical hints use the existing event
envelope; read caches are session-only and require no migration.

M33 native privacy extraction retains the existing Kingfisher hook/transcript
policy IDs, canonical Agent payload bytes, public capture adapter signatures and
Control V3 interpretation. Existing source identities, spool requests and
publication receipts are not upgraded or rewritten by the new library boundary.

M33 acquisition extraction retains all six serialized capture profiles and
product versions, bounded complete headers, exact raw-header/device/inode
witnesses and the Cursor sidecar requirement. JST-COMPAT-001/003/005 repository,
spool and receipt formats remain unchanged; source discovery grants no admission.
