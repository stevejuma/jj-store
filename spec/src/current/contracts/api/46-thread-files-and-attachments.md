# Planned thread file transport

[M35 thread files](../collaboration/45-thread-files-and-attachments.md) plans
bounded binary staging/status, authorized exact-version downloads and typed file
references separate from existing repository attachments. JST-COLLAB-037 through
JST-COLLAB-039 require attachment-only messages, one-home atomic file/reference
publication and independent agent-delivery recovery. Existing JST-API-001/006
admission and receipt semantics govern the future boundary; these routes/fields
are not yet generated, implemented or qualified.
