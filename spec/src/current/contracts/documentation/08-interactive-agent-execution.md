# Interactive agent execution manual

JST-DOC-001 and JST-DOC-002 require the execution guide to distinguish retained
AgentStore history from live device execution state. Document explicit setup and
launch actions, exact isolated workspace selection, negotiated configuration,
permission choices, follow-ups, cancellation, unknown outcomes, capability-gated
resume, labelled context continuation and safe retained-workspace cleanup.

The manual describes trusted executable configuration and installed adapter
authentication separately. Browser bodies cannot configure executables. Ordinary
setup requests contain opaque credential references; M25 additionally permits
explicit write-only device Keychain input, with browser drafts held only in
memory. Source-derived CLI/API/environment references and source review
fingerprints cover the new interfaces. Browser and desktop Help bundle the same
guide; bundled harness availability alone does not qualify a live adapter or a
signed desktop release. Fixture permission proof stays distinct from installed
adapter turns that raised no permission request.

The guide documents Settings → Agents → Runtimes, explicit private Codex
installation/update, pinned versions, Node/npm prerequisites, vendor Cursor
setup, exact installation receipts and restart/failure retention. Readiness,
authentication and connected presence remain distinct. Reference prose records
Buzz's private-path design inspiration without adding a checkout dependency.

M24 adds the reusable fleet and contextual chat guides: in-place Start/Stop,
repository-free personal homes, registered native materialization, exact @ tags,
opt-in reply recipients, scoped drafts and global ACP avatar status. Regenerate
the installation API reference and review changed source fingerprints. Real
native, installed adapter and cold browser gates remain independently recorded
in E-FLEET-001; documentation review never substitutes for them.

M25's local-compute runbook describes device defaults, environment precedence,
Keychain/operator references, explicit native-runtime and model preparation,
trusted pairing, inference-only sharing, bundled helper staging and historical
context inspection. Fixture, real-model and platform distribution evidence must
remain distinct. Headless identity examples name environment references rather
than putting a credential in a command, URL, checkout or transcript. The guide
names the bundled harness jj-agent, describes runtime companion readiness, the
shared defaults model selector and service-machine GGUF Browse followed by
explicit Import. Installation API/type references are regenerated for picker
capability and optional-path results; the model/credential/pairing boundaries
and independent M25 platform gates remain explicit.

The guide identifies Compute model size/fit labels as RAM-based estimates,
retains unknown metadata, and distinguishes draft selection from explicit
download/start. Source review does not claim GPU-fit or real-model
qualification.

The guide describes selected-agent header presence, composer-local reconnect
warnings and completed snapshot file panels shared with the inbox. It identifies
bounded and unavailable text previews, exact saved comparisons and the lack of a
qualified session-specific Undo. These presentation/read controls do not expand
execution authority, rewrite saved history or qualify an inverse mutation.

The manual documents installation-local execution/settings notices, independent
target invalidation and quiet healthy Agents/chat views. Reconnect and bounded
failed-read recovery preserve drafts and pending identities. Source review and
generated public domain references remain distinct from cold event acceptance.

The Settings guide explains that automatic mentions are one installation-wide
saved preference, updated immediately from either Settings or the composer.
Conversation recipient pins and explicit drafts survive disabling it. Unrelated
configuration remains an explicit Save defaults action. All Settings dropdowns
use the shared shadcn controls with keyboard access and labelled defaults.
