explicit native writer from immutable readers and independent vault backup.
Source evidence does not qualify either cold application host or delivery.

E-ORIGINAL-REMOTE-001 proves guarded save, native tracking fetch and one
reviewed branch publication. E-ORIGINAL-REMOTE-002 adds real TLS smart HTTP with
temporary trust confined to the disposable Linux worker; ordinary certificate
and redirect verification remain intact.

E-ORIGINAL-REMOTE-003 documents operation-pinned native graph counts for a known
empty remote and an immutable reviewed commit. Missing local history remains
unknown; a later capture cannot alter the review's proposed commit or counts.
The native root is excluded from empty-branch outgoing counts. Documentation
retains the shared read budget and separate host/credential-custody gates.
