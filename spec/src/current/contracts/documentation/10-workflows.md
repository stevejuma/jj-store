# Workflow documentation

JST-DOC-001 and JST-DOC-002 apply to the native workflow profile. The authored
CLI guide is included in command help and generated parser references. API
references derive from the actual registered WorkflowService routes and schemas.
The guide describes separate metadata/source grants, explicit host admission,
operator-owned commands and environment secret references, pinned source export,
ordered evidence, cancellation and unknown-outcome recovery under JST-WF-001
through JST-WF-007. Version/format limits and live qualification gaps are
explicit.

The browser uses the owned Buzz-inspired view with public Design Core controls.
Documentation distinguishes native workflow YAML from runner-owned Actions YAML;
remote Forgejo runner registration/polling and ConnectRPC remain deferred.
