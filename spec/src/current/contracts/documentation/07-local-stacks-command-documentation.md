# Local Stacks command documentation

The server-free `jj-store stack` family has authored long/keyword help and
parser- generated command reference, including nested workspace, branch and
selection arguments. Documentation distinguishes ordinary snapshots from
nonmutating inspection/dry-run, exact hunk and configuration pins, required
destructive confirmation and applied-operation recovery. The CLI and
ordinary-local technical guides document shared UI TOML/native semantics and
excluded remote/PR workflows. Source review covers CLI, local JJ and shared help
topics in the same change.
