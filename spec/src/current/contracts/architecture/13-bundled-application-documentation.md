# Bundled application documentation

Development and preview startup require a validated initial Help bundle before
listening. Running manifest-driven rebuilds retain the last validated bytes;
incomplete or rejected replacements cannot remove a usable manual. The Help
presentation owner renders its responsive themed skeleton and sends failures to
the app notification owner. Portable same-origin page reads retain the document,
header, theme/font resources and search runtime, validate replacement regions,
resolve their relative assets and cancel superseded reads. This adds no service
state, public API or repository authority.

The application manual is a separate MkDocs Material build from Markdown. Its
static HTML, search and build-time Mermaid SVGs are bundled for browser and
desktop Help. Documentation generators consume command/schema definitions and do
not become repository authority.
