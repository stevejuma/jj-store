# Freshness producer ownership

State owners publish bounded, body-free semantic notices after accepted changes
and asynchronous settlement. Capture observations suppress scheduler-only phase
and resident-frame churn while retaining pause, drain, availability, selected
source, import and queue progress. Local watcher hints never establish committed
state; shared bounded heads/companion checks validate their meaning and cover
missed physical notifications. No browser poll is needed while the advertised
application feed is healthy. Exact task and request receipts remain
authoritative.

Local embedded-operation reference regressions MUST prove cold exact-source
recovery, source-only preparation, forward/backward windows, unchanged outer
snapshot and signed cursor binding. Reject newer and unrelated ready operations,
preserve current authorization, and serve shallow operation relations above the
ordinary commit-history limit without reading unrelated Git bodies.

Prepared local child-selector regressions MUST match the ordinary operation
selector under a small read budget, including mixed parent/child suffixes,
ambiguous branches and later-head exclusion. Selected operation metadata stays
readable without Git bodies or source commit indexes; the retained edge lookup
survives removal of its disposable file. Independently corrupted projections
fail framing/checksum/membership checks before serving.

Native prepared child-selector regressions MUST work under a small metadata
budget with complete inventory enumeration disabled. Cover mixed suffixes,
branch ambiguity, later-head exclusion, selected-only operation reads, cold
bounded behavior and current revocation; native index bytes remain unchanged.

The local browser stack-history regression uses only disposable Git-backed JJ
fixtures and the workspace-built development executable. It verifies bounded
head/base pages, rejected foreign anchors and byte-identical source metadata and
unsnapshotted physical files. Existing LocalTrusted HTTP query/cursor admission
and explicit cold-index preparation are reused; no installed service or user
repository is initialized, modified or converted by this acceptance lane.
