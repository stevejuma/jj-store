# Bundled application documentation

JST-DOC-002 derives the checked-in CLI reference from the registered upstream
command tree augmented with owned extensions and the standalone ServerCli
parser. A development-only example emits the inventory without loading a
repository or invoking commands. Configuration examples use the production
loader; shared authored long help remains embedded in executable help. Generated
manual links translate repository-only capture preview references to the
published capture guide; shared executable help retains its source context.

Application read regression coverage includes manifest-root point membership
under a one-object request budget. The complete inventory remains explicitly
bounded for callers that request enumeration; opening an application content
read no longer enumerates all stored objects.

Local browser metadata conformance includes a retained-operation query and a
deep bookmark page on a ten-thousand-bookmark fixture with corrupt disposable JJ
index segments. Neither request may load that index or traverse commit history.
The opt-in existing-repository smoke is read-only and requires an explicit
metadata directory; ordinary tests never use a developer checkout.

Scoped local file-read regression evidence uses a small history-visit budget to
exclude full operation/commit preflight. Native browsing conformance verifies
directory rows and a deep bookmark window with exactly the operation, view and
selected target object reads. These focused tests retain existing exact diff,
conflict and cursor coverage.

Files-first conformance covers row-only reads under a one-commit budget, exact
local commit/path/file membership, independent commit summaries and shared
bounded attribution. Cold browser acceptance must keep rows usable while
metadata is pending or fails and reject obsolete enrichment after navigation.

Reference startup qualification includes 10,000 bookmarks, exact names outside
the first window, independent workspace reads with an unusable derived index,
shared targets, missing selections and cursor input changes. Browser acceptance
keeps explicit Files and collaboration routes usable during pending picker
reads.

Local and native operation metadata browsing without ID-prefix lookup bypasses
commit-index admission and construction. Reads retain pinned operation ordering
and bounded filtering and must not repair a local commit index. The existing
complete-admission prefix path remains until prepared operation lookup is
qualified.

Serving-composition acceptance MUST block an index preparation storage read and
prove that the configured interactive capacity still serves files and operation
metadata. A second preparation, including through another cache namespace, must
return Busy until the first worker exits. Cancellation and service teardown must
retain that shared preparation permit until exit and then release it.

Local historical file acceptance MUST return a recently reachable ancestor's
directory, commit summary and exact file with a corrupt source index and a small
history budget. Reads preserve index files, reject commits introduced after the
selected operation and retain abandoned/evolution-only membership through its
operation ancestry. Budget exhaustion must remain explicit.

Native graph acceptance MUST exercise a capability that permits checked point
membership but rejects complete inventory enumeration. Cold inline admission,
explicit preparation and warm graph pages must work through that capability,
while hard index/metadata/work/output limits and canceled-worker ownership
remain covered independently.

Native preparation acceptance MUST compare the resulting segment and operation
link byte-for-byte with the pinned upstream cold builder. Fixtures include
equal/skewed timestamps, multi-parent merges and divergent change IDs. Space
tests MUST prove refusal before scratch or streamed output exceeds the shared
allowance; failure leaves no ready entry and permits a later authorized retry.

Preparation-policy regression MUST prove that a small interactive work or
membership limit does not become the explicit task's cumulative limit, while the
original page retains its limit. Trusted preparation ceilings must reject
oversized policy values and enforce stricter configured budgets. Lifecycle tests
must hold a native storage read beyond completed-report retention, retain
Running until explicit cancellation or the separate execution deadline, and
prove cancellation/expiry release the body and worker before completed status.

Warm resident-cache acceptance MUST retain same-size corruption detection even
when a writer restores mtime, plus existing missing-file, receipt, symlink,
repository/epoch, eviction and revocation checks. A low-work warm verification
fixture MUST distinguish metadata checks from full-file hashing. New executors
and process restarts still verify complete disk content.

Shared resident-memory regression MUST prove aggregate native/local admission,
refusal before exceeding capacity, overflow rejection and retention until the
last reader exits. Framing tests MUST reject an allocating parent-name length,
parent cycle, impossible table length and excessive commit count before calling
JJ's decoder. Both native graph and local prepared-read suites exercise the
shared admission boundary; these tests do not qualify total process RSS.

Cache concurrency acceptance MUST hold a warm `all()` page at an authorized
commit read, prepare a newer operation using the same namespace and a one-slot
cache, then release the old read. Preparation must complete and evict the old
disk slot while the original page still returns its exact captured data. The
inverse order MUST also pass: hold preparation after it has evicted the disk
slot, start an ordinary page from the earlier verified resident, and return the
original pinned data before releasing preparation. Reads retain fresh
authorization and no cache-file or native publication side effects.

Cache quota acceptance MUST include multiple operations and epochs of one
repository alongside an unrelated repository. Cold reservation evicts within the
pressured repository first, counts scratch and output in the reservation, and
leaves warm reads available. Restart with a reduced repository quota must
reclaim excess entries before construction without changing native state.

Local preparation acceptance MUST compare complete segment and operation-link
bytes with a cold JJ 0.45.1 index. The fixture includes rewritten history and a
later operation excluded by the pin. Missing source trees and a damaged source
index must not block construction. Verify dirty files, extra metadata, operation
heads and Git refs remain unchanged; dropping, canceling or exhausting a
construction must remove private output. Missing extra records must not trigger
implicit import, and corrupt extra segments must fail before output is retained.

Prepared local log acceptance MUST compare joined one-row pages and filtered
merge graphs with pinned upstream output. Missing source trees, damaged source
indexes and removed derived segment files cannot prevent admitted metadata-only
pages. Current revocation and same-size source-extra mutation with restored
mtime must fail explicitly. Resident admission retains its charge until the
final handle drops; source metadata, refs and dirty files remain unchanged by
reads.

Cross-profile cache qualification MUST prove that two local generations consume
the same repository allowance seen by native cache admission, that another
repository consumes aggregate capacity, and that a reader-held generation
remains charged after task ownership is released. A terminated owner's staged
output must be reclaimed before another reservation is admitted; active
generations must remain readable while the short namespace admission lock is
available.

Local index-task acceptance MUST exercise exact historical pages after newer
operations, duplicate starts, completed-generation eviction, restart reset,
current revocation and changed binding generation. Hold the first preparation
authorization to prove cancellation and expiry release actual worker/quota
ownership while interactive reads remain available. Completed expiry must free
its reservation without status polling. These checks are separate from cold
HTTP/browser delivery and million-commit qualification.

Local preparation HTTP acceptance MUST capture the actual cold-query local pin,
start/status/cancel responses and prepared graph page; unknown trusted-limit
fields are rejected and unknown task IDs reset. Cancel is bodyless under the
existing API admission rule. A cold filesystem-only browser run must load files,
prepare the exact history operation through its recovery action, display the
returned history and preserve physical files, source operations, bookmarks and
companion selection. Keep registry-release qualification distinct from any
documented source-dependency validation setup.

Local point-read regression MUST remove extra heads in a disposable repository,
read an authorized commit/header and bookmark target, and prove that neither
read imports extra metadata. A separately framed source table larger than the
interactive byte allowance must permit a small selected record using bounded
seeks, refuse an oversized selected value, and detect same-size mutation with
restored mtime. Full preparation checksums and ordinary point admission remain
distinct measurements.

Identity-only folder admission MUST remain available when a selected domain
exceeds its read budget or its payload is unavailable; actual domain reads must
still fail closed. Unselected staged roots remain invisible and a damaged
selected metadata commit must fail identity observation. Cold filesystem serving
with recorded Agents must exercise this path through ordinary code requests and
freshness polling, independently of full collaboration validation.

Local diff/conflict acceptance MUST read a selected file comparison,
changed-path summary and selected conflict descriptor with a history-visit cap
below the repository's unrelated history. Preserve exact content/terms and
unchanged source extra-table heads. Unknown targets remain rejected; the full
local browser suite retains conflict/operation/dirty-file qualification.

Prepared local point-read regression compares historical summaries, directory
rows, scoped file content, diffs, changed paths and conflict descriptors with
the ordinary reader, under a history-visit cap that rejects the cold deep proof.
The prepared reader must survive source-index corruption and disposable segment
loss, preserve exact terms/content, reject later commits and mismatched file
IDs, and leave source extra heads unchanged. These focused checks are delivery
evidence; complete large-repository and cold lifecycle qualification is
deferred.

Prepared reference-page regression MUST compare Changes/All forward, backward,
deep and exact windows with ordinary local semantics, including divergent
changes, hidden rewrites and conflicted bookmarks. With a history-visit cap
below the visible closure, hydration stays within selected-page targets;
source-index loss, later operations and differing embedded selections remain
explicitly tested. Complete pressure/browser/lifecycle qualification is
deferred.

Native prepared-decoration regression MUST prepare with a separately bounded
construction budget, serve a warm selected row below the work required to scan
unrelated references, and reject a row whose own annotation output exceeds its
ordinary work budget. Verify local/remote identity and workspace labels, pinned
visibility/divergence and unchanged manifest state. Keep exact native graph and
cache consumers in the focused delivery checks; large-scale and full lifecycle
qualification remains deferred.

Native projection recovery acceptance MUST reopen a previously prepared disk
generation through a fresh executor, observe rebuild-required under a lower
inline threshold, explicitly prepare and reproduce the exact pinned rows without
changing the manifest.

Shared resident admission regression MUST prove global ordering across native
and local cache owners, refusal without eviction for oversized requests,
nonblocking admission while a cache slot is busy, and retained
charges/readability for an executing reader. Exact native cache and local
preparation-task tests remain the direct delivery consumers; full pressure/RSS
qualification is deferred.

Native construction delivery regression MUST prepare a small repository within
a64KiB cache policy, compare multiple historical operation scopes with ordinary
pinned results, resume warm reads and leave the native manifest unchanged.
Scratch tests MUST reject oversized ordered-table growth before retaining data
and preserve forward/reverse/keyed ordering. Focused native graph and local
prepared-read consumers remain required because they share the owned format
writer. Complete scale/RSS and combined lifecycle qualification remain deferred.

Historical native resident reuse regression MUST prepare the selected and
ancestor operations independently, then evaluate multiple historical scopes with
an inline threshold below each closure. Compare ordinary pinned semantics,
assert that the selected slot's file receipt does not grow, and repeat the warm
read. Direct corruption, binding, revocation and resident lifetime consumers
remain part of focused delivery evidence; full scale qualification stays
deferred.

Native graph fixture coverage MUST distinguish missing-primary construction,
warm resident reuse and existing-disk projection recovery after executor loss.
Private recovery retains current native operation/view admission, hard/inline
limits, selected visibility and cancellation cleanup while unrelated cache
preparation proceeds. Focused fixture evidence does not qualify Linux/native
scale, production browser or release behavior.

Filesystem-browser preparation regressions cover retained operation-prefix
selection, ambiguity, suffixes and small read budgets without source index
repair. This adds no installed CLI command; complete scale/lifecycle and release
qualification remains deferred.

Local prepared-filter regression MUST compare Unicode whole-string substring
matching, short and sparse filters, hidden rewrites, divergence, removed
bookmark terms and forward/backward/deep windows with the ordinary reader under
a smaller history-visit budget. Prove selected-only source hydration with an
unrelated Git body unavailable and source/prepared index files unavailable after
admission. Owned projection regressions additionally cover compressed block
seeks, checksums, operation selection, growth admission and canceled/budgeted
queries. Actual local HTTP evidence MUST retain cold exact-operation recovery,
prepared retry and query-bound signed forward/backward cursors. Complete
large-repository and production browser qualification remains deferred.

Native prepared-filter regression MUST compare 108 bookmark/change/all windows
against complete ordinary pinned results across Unicode, sparse/missing text,
hidden predecessors, divergent visible targets, removed bookmark terms and both
directions with arbitrary anchors. An ordinary history budget below the fixture
closure must still serve the prepared page while reading only its selected
target bodies. Preserve unfiltered and small-cache bounded behavior.

Native filtered-cache acceptance MUST upgrade an index-only generation through
explicit preparation and verify pinned cold recovery, executor loss and restart.
When another readonly reader owns its disk generation, failed inline recovery
must leave the files and byte charge intact. Successful recovery replaces the
same slot without duplicate accounting. Pressure tests must hold an executing
reader while a third operation needs a two-slot cache, reclaim an idle filtered
resident and preserve the executing reader's exact rows, files and charge. Unit
evidence must refuse deleting or uncharging active pinned slots and skip them
when another generation is removable. Complete process/fault/RSS and
large-repository qualification stays deferred.

Focused native HTTP evidence must cover filtered cold recovery through the
explicit index task, compare unfiltered first-page identities, and preserve
query-bound signed forward/backward cursors across later publication. The
original snapshot remains selected; complete contract/browser qualification is
still separate.

Native admission arithmetic must distinguish bounded reader memory from complete
filter-file disk quota for a two-million-row index, without raising the process
pool. This private regression proves retention arithmetic, not measured RSS or
large-repository serving.

Cold native cache regressions MUST prove namespace admission does not charge
complete file hashing and that another reader can open the namespace during the
digest phase while the full actual-size reservation or pinned slot remains
charged. Prove checksum failure before native reads, automatic private rebuild,
shared corruption preservation, cancellation/work failure cleanup and the
coarse-metadata final proof before installation. Existing cold recovery,
preparation, filter upgrade and pinned-query consumers remain focused gates;
complete scale/browser/fault qualification stays deferred.

Native embedded-operation reference regressions MUST select historical
Changes/All and description-filtered bookmark windows under an independently
pinned outer read. Compare both directions and arbitrary anchors with the
ordinary reader, retain exact page operation and outer snapshot, and serve a
prepared source above the ordinary history budget without preparing the outer
operation. Prove exact-source cold preparation, unchanged later-publication
windows, and rejection of newer or unpublished operations absent from the outer
capability even when their cache is ready. Warm generations retain current
authorization and point membership; complete qualification stays deferred.
