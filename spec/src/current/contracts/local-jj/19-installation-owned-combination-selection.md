# Installation-owned combination selection

The private combination catalog MUST bind installation, configured principal,
repository, physical workspace, JJ workspace name and supported code profile.
Its explicit creation starts with no active combination. Open, snapshot and
current selection never create setup. Names, target refs, stable stack IDs,
ordered stack heads, immutable boundaries, exact merge/WIP identities and
retention anchors are device state, never portable companion authority.

A provider-derived proposed state MUST be durably staged before publication,
under the original authenticated preview and acknowledged retained archive.
Every new or changed combination reference MUST belong to that exact retained
code closure; unchanged combinations keep their prior retention anchors. Staging
checks the prior revision, active selection and code pin. One pending update
blocks new preparations and retains the prior selected state for recovery. No
active pointer or generation advances from a pending preview.

Legacy selection requires the matching journal's original principal, scope,
preview, retention linkage and completed checkout receipt. New coordinated
execution follows the ordered join below. Rejection may discard only an
unpublished matching pending update. Exact retries retain historical outcomes
and cannot replace current state with an earlier selected combination. Names and
IDs are unique, generations increase only for changed entries, and all record,
byte and graph-reference bounds fail before selection. Records are never evicted
for capacity. Atomic replacement, private-file identity checks, synchronization
and acknowledgement-loss recovery reuse the installation file policy.

This metadata owner alone cannot attest actual operation publication or
checkout. Runtime MUST supply qualified provider evidence to the existing
journal before selecting a combination. Setup, merge/WIP generation, switching,
membership, source restoration and guarded checkout remain required execution
gates. Neither metadata fixtures nor a durable reader enables a writable
capability.
