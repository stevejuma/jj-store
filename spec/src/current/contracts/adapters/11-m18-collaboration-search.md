# M18 collaboration search

[Collaboration inspection/search](../collaboration/index.md) indexes selected
canonical agent/review documents as rebuildable projections. Agent/review
freshness remains independent of code freshness. Recheck current target/body
visibility before returning snippets, facets, counts or links, including
historical and lagging segments. Search outage never blocks first-party reads or
capture publication.

Search freshness observes the adapter owner's existing health channel. Exact
applied/remote/frontier and degraded-state changes invalidate the search domain;
unchanged worker observations and stream renewal do not refetch browser pages.
The health observation is rebuildable and cannot select repository authority.
