# Device-local link commands

Linking a physical workspace changes only installation-owned discovery state. It
is not a repository publication, checkout operation or captured AgentStore
delta. Native snapshots and receipts remain unchanged. The server resolves a
validated native binding before a revision-checked update; identical retry
intent returns the selected existing link after an uncertain acknowledgement. A
different folder with a stale revision fails explicitly. No device link grants
repository access, permits a different principal, or enables an unqualified
backend. Every transport request retains the local-administration guard.

Device-local folder selection uses a separate owned `FolderPicker` service
interface. It returns a bounded draft path or cancellation, never a workspace
proof, publication or saved link. Transport admission precedes helper execution;
workspace verification remains read-only and linking retains its existing
checks.

Owned local Sync management contracts describe credential-free
configured/local-only status and typed pause/resume/retry commands. The server
adapter reuses existing control-plane operations rather than publishing
repository mutations.

Local Search configuration and operation reports use owned service types. These
settings affect rebuildable adapters only and cannot publish repository state.
The server owns file revisions, persistence, worker draining and activation;
transport admission independently verifies local administrative access.

Local Thread, Reaction and emoji-library commands share the jj-collab projector
and retain a typed result in the companion receipt. Callers cannot supply an
actor. Reaction targets and explicit session/review links are validated against
the same captured metadata commit used for expected-old-ref publication; a race
reloads every source selection before retry. Human edits retain exact revisions,
primary session reassignment preserves historical links, and custom image
definitions use exact version preconditions. Reads neither initialize metadata
nor establish an actor. Local query pages suppress current hidden/tombstoned
targets and preserve earlier-version distinctions. Native command adapters,
HTTP/RPC/CLI exposure and atomic capture binding remain pending qualification.
