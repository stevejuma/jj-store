# M15 additive collaboration publication

Threads and Reactions use independently selected canonical roots and immutable
complete-closure inventories. Native manifest format 5 adds optional roots and
state versions; local companion version 2 extends the owned ref envelope on
first feature use. Earlier formats remain byte-identical. Publication providers
retain original request receipts and expected-state checks; staging is
invisible. Cold recovery and copy audit all current and historical selected
roots, including raster assets and external AgentStore/ReviewStore/code
dependencies. Reducer 3 qualification precedes replicated collaboration
publication; unsupported origins fail closed. No replay executes agents or
fetches image bytes.

Target resolution composes the selected Thread graph with audited AgentStore and
ReviewStore read facades captured from the same authorized snapshot. Unselected
collaboration objects and staged agent/review records are excluded. The owning
record readers preserve and verify existing repository-bound Agent/Review object
IDs; collaboration content IDs remain separate. A newer selected tombstone or
moderation state suppresses historical reaction disclosure without changing an
older explicit read pin. Resolver reads do not publish or reconcile repository
state.

Local maintenance captures one checked manifest and digest before work.
Integrity audits that exact capture under the coordinator history, inventory,
byte and time bounds; an exhausted bound is incomplete, never healthy.
Checkpoint preparation persists that capture in the private device journal
before dispatch. Repeated publish and status requests retain it, even after
disconnect or restart. Selected authority distinguishes the exact checkpoint
from coverage by a newer checkpoint; coverage does not prove that the original
write succeeded. Neither path prunes retained records or replaces a newer tail.

Review dependency closure now enumerates portable code-evidence references as
well as native and agent edges. Local file-review publication selects the source
capsule inventory and its complete Git reachability with the review root. Local
Thread/Reaction consumers retain that same evidence when referencing review
records. Native staging and reads reject portable review carriers; this
extension does not weaken native dependency verification or qualify conversion
carriers.
