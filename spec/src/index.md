# Native JJ Store specification

This book is the canonical behavior contract. Read
[architecture](architecture.md), [governance](spec-governance.md),
[milestones](milestones.md), and [verification](verification.md) before
implementing a slice. Native commit, operation, evolution, and publication
histories remain distinct.

The first release serves new native repositories with repository-scoped tokens.
See the [accepted implementation plan](../../docs/implementation-plan.md) and
[reference archive](../../docs/reference/README.md) for background.
