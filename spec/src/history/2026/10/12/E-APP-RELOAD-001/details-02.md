## Protected behavior

Reload validates the saved file revision and supported requested domains before
selection. The principal-bound original command and outcome are journaled; an
unknown acknowledgement retains the original request and never replays it.
Fresh independent ManageConfiguration authority covers configuration domains;
ManageAgents alone covers remote-agent activation, not service settings or
repository access. Repository Write never grants execution authority.

Protection and sharing replacement wait for the exclusive publication lease.
Admitted operations hold their read lease through manifest CAS; native,
collaboration, application, replication import and seed publication retain this
fence. Manifest CAS remains the only repository publication authority.

Ordinary reusable HTTP/RPC consumers retain explicitly supplied resource limits.
The server opts into its retained live policy. New HTTP/RPC requests, uploads,
native sessions and query jobs capture current limits; already admitted work
retains its original bounds. Read cursors, operation selections and snapshot pins
are unchanged. S3 limits update on the retained client without rebuilding storage.

Capture drains before replacement, retaining generations, pause policy, spools
and original import receipts. First enable performs only fresh initialization
under retained server/storage locks. Search uses its existing Apply owner. Sync
preserves checkpoint observations only for an unchanged upstream/token-reference/
CA binding, so a changed peer cannot inherit its predecessor's observations.
Remote agent leases survive allowed reloads and freshly revoked callers lose
session/event access. Active local worker launch and Compute relay changes may
report Deferred until their next existing Stop/Start workflow.

cache and two test threads. Cold executable/browser qualification remains a

unsupported. After moving the main executable to ignored runtime storage,
`pnpm dev:clean -- --apply` freed build artifacts without touching application
state, embedded RustFS, desktop resources, configuration or dependencies.

Inherited notices are Node module.register deprecation, missing optional Svelte
config, the macOS linker unwind-table-size warning and bundle-size warnings.
They are recorded separately from functional failures. Root aggregate spec,
check, test and build lanes remain out of scope under targeted policy.
